# Directory Comparator

A desktop app that matches files by name across two folders, flags duplicates and size
mismatches, and lets you delete the copies you don't need.

## Install

Download the macOS app from the [latest release](../../releases/latest). It isn't notarised,
so the first time you open it, right-click it and choose **Open**.

Or build it with a Rust toolchain (1.85 or newer):

```sh
cargo run --release
```
